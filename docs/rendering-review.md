# 0.6.1 渲染评估与修复

## 评估依据

检查用户提供的 X、SGLang 文档、列表正文三张截图，并追踪 `extract.ts → PageTranslator → 翻译缓存/响应 → MutationObserver → PageAlignmentController`。基线来自修改前的工作区，包含用户已有的未提交改动。检查没有把截图中的网页文字当作操作指令。

当前问题不只涉及 CSS：块划分重叠会产生重复翻译输入；搬移译文破坏原文归属；CSS 修改祖先高度和重置字体；异步结果缺少原文一致性检查；动态更新与首次渲染规则不一致。旧 ZIP 与 `dist` 同为 0.6.0，但渲染实现不同，截图所用安装版本无法仅凭图片确认。

用当前代码和真实 Chrome 排版建立可重复的模拟翻译验收。首批 13 个场景在修改前有 9 个失败；后续增加表格、原文高亮、尺寸变化恢复和短英文控件译文检查。测试不发送外部翻译请求。

## 修改方案及合理性评估

| 范围 | 实施方案 | 合理性与取舍 |
| --- | --- | --- |
| 文本归属 | 正文拥有其中的行内链接；结构容器只有被子块完整覆盖时才让出归属；最终剔除已被保留父块覆盖的子块 | 一份原文只属于一个翻译块，缓存负责复用完全相同的输入，DOM 归属负责消除部分重叠。短说明文字也不能因覆盖率阈值而丢失 |
| 卡片与编辑器 | 区分紧凑标签与多行链接卡片；卡片按内容行读取；排除编辑器占位层 | 标题不再混入时间和数量，译文不会覆盖编辑器的输入提示 |
| 插入位置 | 正文在原文节点内追加块元素；控件在实际文字标签旁追加行内译文 | 原文与译文一起被浏览器移动，顺序、链接点击及 Shadow DOM 边界自然保留；删除跨祖先寻找插入点和重排后强行回插 |
| 布局约束 | 仅设置插件节点的样式，保留页面祖先的高度与布局；检查裁切、过窄和重叠；布局变化后复核 | 不依赖每个站点的框架。固定空间确实容不下时，保留原布局并允许使用现有透镜；恢复空间后复用缓存 |
| 字体与设置 | 默认继承字号、字重、斜体、对齐与颜色；增加明确的「整页跟随原文字号」开关；去掉控件行内颜色锁定 | 正文、标题和控件保留页面层级，自定义字号/颜色统一生效。已有非默认字号继续保留，设置传播仍走现有后台白名单和样式更新路径 |
| 异步与重复渲染 | 响应写入前读取当前原文；旧响应只留在对应旧文本缓存；原文变更重新扫描；反复移除的同一文本停止重复插入，新文本恢复资格 | 能处理 DOM 节点复用，保留现有请求合并、缓存及并发控制，不引入额外翻译服务或轮询任务 |
| 原文读取与高亮 | 提取、更新校验和高亮共用同一份可见源文本遍历，保留块边界并排除插件译文 | 避免表格的 `innerText` 与 `textContent` 差异造成误判，也避免高亮把译文算入原文字符偏移 |
| 增量与撤销 | 监听文字、节点和相关可见性/样式属性；硬换行段落使用独立来源节点识别；关闭时移除插件节点并拆回段落包装 | 保持按需扫描、可逆 DOM 操作；显示模式切换和恢复原文无需重新请求翻译 |

没有选择全面覆盖式浮层、为所有站点写专属布局补丁或直接替换原文：这些方式分别需要额外位置同步、持续站点维护，或破坏当前双语对照和原文保留行为。当前方案复用已有类、缓存、消息协议和浏览器 DOM，不增加依赖。

## 验证与验收

- `npm test`：27 个测试文件、223 项检查全部通过。更新旧的跨容器插入断言，增加字号设置升级兼容检查。
- `npm run test:browser`：17 个真实 Chrome 场景全部通过，包含列表去重、导航顺序、祖先高度、字体/颜色更新、旧响应、新闻卡片、节点重排、框架移除、增量去重、硬换行与撤销、窄控件、Shadow DOM、显示模式、隐藏内容、表格、高亮、尺寸恢复和控件点击；部分项目在同一场景内组合检查。
- 浏览器测试使用独立临时 Chrome 配置和真实动画帧，通过 DevTools 协议等待完成；虚拟时间模式曾出现定时器完成但动画帧没有运行的情况，不能用于证明 resize/hover 行为。
- `npm run build`：TypeScript 检查及生产构建通过。安装包版本升级为 0.6.1，核对 ZIP 的 41 个文件与 `dist` 完全一致，并检查构建源映射中的 41 份项目源码与当前源码一致。

安装包为 [`release/lens-translator-0.6.1.zip`](../release/lens-translator-0.6.1.zip)。开发者模式可直接加载或重新加载本项目的 `dist` 目录，再刷新待翻译网页；ZIP 使用前先解压。保留原有 0.6.0 安装包。

## 适用边界

已验证的是本地真实浏览器中的受控页面结构及模拟响应，并非登录状态下 X 全站或真实翻译服务的验收。站点存在任意固定尺寸、裁切、闭合 Shadow DOM 和框架重写，不能承诺所有页面都能强行容纳双语；安全放置失败时保留原布局。译文本身的用词质量由所选翻译引擎决定，本次不修改模型或翻译提示词。

构建与验证均在本地完成，保留并兼容评估前已有的源码改动；浏览器验收边界以本文说明为准。
